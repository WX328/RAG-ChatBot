# RAG ChatBot

基于 LangChain + Streamlit + 大语言模型实现的知识库问答系统。

## 项目功能

- PDF文档解析
- 文本切片
- Embedding向量化
- Chroma向量数据库
- LangChain LCEL RAG Chain
- 多轮对话记忆
- Streamlit网页聊天界面


## 技术栈

Python

LangChain

OpenAI API

ChromaDB

Streamlit
